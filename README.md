# แผนกจัดการงานก่อสร้างระบบส่งและสถานีไฟฟ้า
### กองก่อสร้างระบบไฟฟ้าและงานโยธา ฝ่ายวิศวกรรมและบริการ
### การไฟฟ้าส่วนภูมิภาค เขต 3 (ภาคกลาง) จังหวัดนครปฐม

Web Portal หน้าแรกสำหรับการเข้าถึงและบริหารจัดการระบบสารสนเทศ การกำกับดูแล ควบคุม และติดตามงานก่อสร้างระบบโครงข่ายไฟฟ้าแรงสูงและสถานีไฟฟ้า การไฟฟ้าส่วนภูมิภาค เขต 3 (ภาคกลาง) จังหวัดนครปฐม

---

## 🚀 ระบบงานหลักที่เชื่อมโยง (3 Web Applications)

1. **Dashboard สถานะงานก่อสร้างสายส่งและสถานีไฟฟ้า**
   - URL: [https://dashboard-constrution-report.vercel.app/](https://dashboard-constrution-report.vercel.app/)
   - ศูนย์รวมรายงานภาพรวมและสถิติความก้าวหน้าโครงการก่อสร้างสายส่งและสถานีไฟฟ้า, วิเคราะห์ S-Curve, แผนที่ GIS รายโครงการ
2. **PCTS (PEA Construction Tracking System)**
   - URL: [https://pcts-psctm.vercel.app/](https://pcts-psctm.vercel.app/)
   - ระบบบริหารและติดตามงานก่อสร้างระบบส่งและสถานีไฟฟ้าสำหรับวิศวกรหน้างาน ตรวจเช็ก Inspection Checklist และการตรวจรับงวดงาน
3. **ระบบคำนวณการคืนพัสดุประเภทเศษเหล็ก**
   - URL: [https://pea-scrap-calculator.vercel.app/](https://pea-scrap-calculator.vercel.app/)
   - เครื่องมือคำนวณน้ำหนักและประเมินมูลค่าพัสดุเศษเหล็ก เสาโครงเหล็ก และสายส่ง เพื่อส่งคืนคลังพัสดุตามระเบียบการไฟฟ้าส่วนภูมิภาค

## 🎯 7 ภารกิจหลักประจำแผนก

1. **วางแผนงาน ประสานงาน ติดตาม เร่งรัด งานก่อสร้าง ย้ายแนวสายส่ง** ให้เป็นไปตามแผนงาน/โครงการ
2. **ประสานงาน ติดตาม เร่งรัด ควบคุมงานก่อสร้างสถานีไฟฟ้า** สถานีไฟฟ้าชั่วคราว โรงจักรพลังงานน้ำ และสถานีพลังงานทดแทน ให้เป็นไปตามแผนงาน/โครงการ
3. **จัดการงานก่อสร้างสถานีไฟฟ้าชั่วคราว**
4. **ประสานงาน ตรวจสอบและทดสอบก่อนการจ่ายไฟ (Commissioning)**
5. **วิเคราะห์ประเมินผลความสำเร็จของแผนงาน/โครงการ** ปัญหาอุปสรรคและนำเสนอหน่วยงานที่เกี่ยวข้อง เพื่อนำไปปรับปรุง พัฒนา
6. **ประสานงาน ติดตาม เร่งรัด การปิดงานก่อสร้าง**
7. **จัดทำรายงานสถานะงานโครงการ**

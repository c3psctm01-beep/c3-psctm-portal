# แผนกจัดการงานก่อสร้างระบบส่งและสถานีไฟฟ้า
### กองก่อสร้างระบบไฟฟ้าและงานโยธา ฝ่ายวิศวกรรมและบริการ
### การไฟฟ้าส่วนภูมิภาค เขต 3 (ภาคกลาง) จังหวัดนครปฐม

Web Portal หน้าแรกสำหรับการเข้าถึงและบริหารจัดการระบบสารสนเทศ การกำกับดูแล ควบคุม และติดตามงานก่อสร้างระบบโครงข่ายไฟฟ้าแรงสูงและสถานีไฟฟ้า การไฟฟ้าส่วนภูมิภาค เขต 3 (ภาคกลาง) จังหวัดนครปฐม

---

## 🚀 ระบบงานหลักที่เชื่อมโยง (5 Web Applications)

1. **Dashboard สถานะงานก่อสร้างสายส่งและสถานีไฟฟ้า**
   - URL: [https://dashboard-constrution-report.vercel.app/](https://dashboard-constrution-report.vercel.app/)
   - ระบบรายงานภาพรวมสถานะงานก่อสร้างสายส่ง 115 kV และสถานีไฟฟ้า ในพื้นที่ความรับผิดชอบของ กฟก.3 ติดตามความก้าวหน้าโครงการ สถานะงานขออนุญาตหน่วยงานภายนอก (Permit) และการเบิกจ่ายงบประมาณสถานีไฟฟ้าชั่วคราว
2. **PCTS (PEA Construction Tracking System)**
   - URL: [https://pcts-psctm.vercel.app/](https://pcts-psctm.vercel.app/)
   - ระบบบันทึกและติดตามสถานะโครงการก่อสร้างระบบส่งและสถานีไฟฟ้า ช่วยให้ผู้ควบคุมงานและผู้เกี่ยวข้องตรวจสอบสถานะโครงการ อัปเดตความก้าวหน้า แนบภาพถ่ายหน้างานจริง ทั้งงานดำเนินการเองและงานจ้างเหมา
3. **ระบบคำนวณการคืนพัสดุประเภทเศษเหล็ก**
   - URL: [https://pea-scrap-calculator.vercel.app/](https://pea-scrap-calculator.vercel.app/)
   - เครื่องมือช่วยคำนวณน้ำหนักพัสดุประเภทเศษเหล็กและสายไฟฟ้าจากการรื้อถอน โดยนำเข้าข้อมูลจากรายงานปิดงาน SAP (ZPSR018) และคำนวณตามเกณฑ์น้ำหนักมาตรฐาน เพื่อจัดทำเอกสารส่งคืนคลังพัสดุ กฟภ.
4. **คู่มืออุปกรณ์ไฟฟ้าสำหรับการก่อสร้างสายส่งแรงสูง 115 kV (PEA 115 kV Material Hub)**
   - URL: [https://115k-v-mat-manual.vercel.app/](https://115k-v-mat-manual.vercel.app/)
   - ระบบสืบค้นข้อมูลพัสดุอุปกรณ์มาตรฐานสำหรับการก่อสร้างสายส่ง 115 kV จัดทำโดย กมฟ. และ กคพ.4 รวบรวมรหัสพัสดุ SAP สเปกทางเทคนิค แบบมาตรฐาน แผ่นคู่มือมาตรฐาน 111 หน้า และระบบใบเบิกพัสดุ (BOM)
5. **ระบบผู้ช่วยจัดซื้อจัดจ้าง กฟภ. (PEA Smart Procurement Assistant)**
   - URL: [https://pea-smart-procurement.vercel.app/](https://pea-smart-procurement.vercel.app/)
   - ระบบผู้ช่วยบริหารจัดการงานจัดซื้อจัดจ้างตามระเบียบ พ.ร.บ. การจัดซื้อจัดจ้างภาครัฐ พ.ศ. 2560 ช่วยติดตามขั้นตอน To-do list 7 ขั้นตอนหลัก ร่างเอกสารและหนังสือราชการ พร้อมระบบแจ้งเตือนข้อกำหนดตามระเบียบกฎหมาย

## 🎯 7 ภารกิจหลักประจำแผนก

1. **วางแผนงาน ประสานงาน ติดตาม เร่งรัด งานก่อสร้าง ย้ายแนวสายส่ง** ให้เป็นไปตามแผนงาน/โครงการ
2. **ประสานงาน ติดตาม เร่งรัด ควบคุมงานก่อสร้างสถานีไฟฟ้า** สถานีไฟฟ้าชั่วคราว โรงจักรพลังงานน้ำ และสถานีพลังงานทดแทน ให้เป็นไปตามแผนงาน/โครงการ
3. **จัดการงานก่อสร้างสถานีไฟฟ้าชั่วคราว**
4. **ประสานงาน ตรวจสอบและทดสอบก่อนการจ่ายไฟ (Commissioning)**
5. **วิเคราะห์ประเมินผลความสำเร็จของแผนงาน/โครงการ** ปัญหาอุปสรรคและนำเสนอหน่วยงานที่เกี่ยวข้อง เพื่อนำไปปรับปรุง พัฒนา
6. **ประสานงาน ติดตาม เร่งรัด การปิดงานก่อสร้าง**
7. **จัดทำรายงานสถานะงานโครงการ**
